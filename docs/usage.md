# ビルドと使い方

## 開発環境から起動する

Windows x64、Git、Python、MSYS2 UCRT64のGCC/G++を使います。GCC 16.1.0で動作を確認しています。表示にはOpenGL 3.3対応の環境が必要です。

ソースを取得して、リポジトリのフォルダでPowerShellを開きます。

```powershell
./setup.ps1
./build.ps1 -Configuration Release
./build/Release/LineTracerSimulator.exe
```

setup.ps1は固定版のCMake/Ninjaと依存ソースを取得します。初回はネット接続が必要です。既定のGCC配置は`C:/msys64/ucrt64/bin`です。別の場所なら次のように指定します。

```powershell
./build.ps1 -Configuration Release -ToolchainBin 'D:/msys64/ucrt64/bin'
```

アプリ内ビルド用のGCCは既定の配置、続いてPATHから検出します。別の配置を使う場合は、そのbinをPATHへ追加してからアプリを起動してください。

## コースを描いて走らせる

1. 「新規」で空のコースにし、「描画」でドラッグします。線幅はmm単位です。
2. 「開始位置」で位置をクリックし、次のクリックで向きを指定します。数値入力も使えます。
3. 「2 制御コード」でC++を編集し、「ビルドして反映」を押します。
4. 「3 実行」で走行します。初回やロード直後は、保存したコードを自動でビルドします。
5. 「一時停止」で止め、「リセット」で開始状態へ戻します。

「選択・移動」で線を動かし、「消去」で1ストロークを消せます。「元に戻す」「やり直す」はCtrl+Z/Ctrl+Yでも操作できます。ホイールでズーム、中ボタンドラッグで表示を移動します。編集を確定すると走行状態はリセットされます。

センサ値・左右指令・時間・位置・1ステップ実行は「実行データ・詳細」にあります。緑のセンサ点は黒線、橙は白地を表します。

## セーブとロード

「セーブ」でコース・開始姿勢・車体設定・C++コードを保存します。既定の保存先は実行ファイル横の`projects/my_project/project.json`です。「保存先・読込先」で変更できます。

コードはプロジェクト内のsourcesフォルダに保存するため、移動するときはフォルダ全体をコピーしてください。「ロード」後は開始状態へ戻り、実行時にDLLを再生成します。軌跡と操作履歴は保存対象に含めません。

## C++コードの扱い

[controller_api.h](../controller/controller_api.h)が公開APIです。入力は経過時間・刻み幅（秒）と可変長センサ配列（白0、黒1）、出力は左右の指令[-1,1]です。負値は逆転を表します。

ビルドに失敗した場合はログを表示し、直前の正常なDLLを保持します。DLLはアプリと同じプロセスで動きます。ご自身が信頼できるコードを使用してください。

## 自動試験

```powershell
./.tools/cmake/data/bin/ctest.exe --test-dir build/Release --output-on-failure
```

6件中、app_smokeは実ウィンドウを開く試験です。GitHub ActionsではGUI以外の5件を実行します。
