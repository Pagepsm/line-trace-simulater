# 検証記録

確認日: 2026-11-05（日本標準時）。対象はWindows x64の開発PCで動作するC++アプリである。

## 開発PCでの確認

GCC 16.1.0、CMake 4.4.4、Ninja 1.13.2を使用。Releaseビルドと以下の自動試験6件を実行した。

| 試験 | 確認する内容 |
|---|---|
| physics_world_lifecycle | Box2D Worldの生成・破棄と独立性 |
| app_smoke | 実ウィンドウで30フレーム描画し正常終了 |
| closed_loop | 駆動、旋回、ラインセンサ、固定刻み、リセット |
| project_editor | コース編集とUndo/Redo、開始姿勢 |
| controller_build_reload | C++ビルド、DLL切替、API不一致拒否、失敗時の旧DLL保持 |
| project_roundtrip | 車体設定・線・姿勢・ソースの保存復元、日本語パス、復元後のビルドと走行 |

実UIでは手書き、幅変更、開始姿勢の指定、C++編集からビルド、直進/旋回コードの切替、コンパイル失敗後の走行継続を確認した。セーブ→終了→再起動→ロード→保存ソースの再ビルド→走行も確認した。

公開候補を別フォルダへ配置し、setup.ps1による依存の新規取得、Releaseビルド、6件すべてのCTest成功を再確認した。
