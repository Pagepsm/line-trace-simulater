# 実装の構成

## センサから車体へ戻る閉ループ

```text
TrackModel → SensorSystem → ControllerInput → C++ DLL
     ↑                                         ↓
 車体位置 ← Box2D Body ← DriveModel ← ControllerOutput
```

黒線は光学情報であり、物理的な壁にはしない。描画とセンサ判定は同じTrackModelを参照する。車体の位置と向きはBox2D Bodyを正本とし、表示用の座標を独立に動かさない。

| 場所 | 責務 |
|---|---|
| src/app | 操作と状態遷移の調停 |
| src/ui | 画面表示、コース編集、入力イベント |
| src/simulation | Box2D Worldの寿命、固定刻み、車体への力 |
| src/track | ストロークと線への幾何距離判定 |
| src/controller | コンパイラ起動、世代別DLL、API検査と切替 |
| src/project | 設定、編集履歴、JSON保存と復元 |

## 物理と座標

矩形の差動二輪車をゼロ重力の平面で動かす。左右車輪位置への駆動力に加え、前後・横方向・角速度の抵抗を明示的に与える。見下ろし平面の路面抵抗をBox2Dの接触摩擦で代用しない。

物理は既定1/120秒、内部サブステップ4で進める。画面のズームと物理座標は分離する。寸法・質量・駆動力・抵抗係数・センサ配置は[vehicle.cfg](../assets/vehicle.cfg)に置く。これらは実機測定値ではなく、変更可能なシミュレーション設定である。

## C++制御器の切替

APIはC ABIのPOD構造体と固定幅整数で定義する。Box2DやGUIの型を公開しない。DLLのversion、構造体サイズ、必須関数を検査し、成功時だけ切り替える。

コンパイラはシェルを介さず別プロセスで起動する。ビルドはバックグラウンドで行い、その間はシミュレーションを停止する。出力を世代別フォルダへ置き、ロード中DLLの上書きを避ける。新DLLの検査に失敗しても旧DLLは残る。

## 保存の単位

JSONのformat_versionは1。コース、線幅、開始姿勢、車体・センサ設定、C++ソースへの相対パスを保存する。ソースを世代別に書き出してからJSONを置換し、保存世代の混在を防ぐ。読込は形式と値、参照先を検査した後で反映する。
